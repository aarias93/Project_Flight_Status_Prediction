Instrucciones para la elaboración del trabajo en grupo



El grupo deberá seleccionar un conjunto de datos que sea superior a 1.5GB.

1. Realice los siguientes procesos con ese conjunto de datos, siguiendo la metodología CRISPDM  
    - Identifique el conjunto de datos y defina el objetivo de análisis y la unidad de análisis
    - EDA - Exploración general del conjunto de datos, realizando analítica descriptiva, tipos de datos, medidas de tendencia central, distribuciones, patrones en los datos., buscando identificar y construir  la variable objetivo y las características para un posible modelo.
    - Realizar el anaĺisis preliminar del conjunto de datos e identificar si se requiere información adicional de contexto.
    - Definir al menos un flujo de trabajo con prefect para un parte de los datos relevantes, que permita realizar una analitica de manera recurrente y escalable, es decir, si llegara otro conjunto de datos similar, o mas datos, el ETL construido con Prefect debe transformar y hacer la analitica respectiva nuevamente.
    - Usar la libreria de Dask en alguna parte del proceso de transformación o análisis de la información evidenciando al menos dos configuraciones de workers y memoria por worker.
    - Construir una base de datos en Amazon AWS, con los datos que resulten del proceso analítico
      NOTA. SOLO DEBEN SUBIR A AWS EL RESULTADO DE LA ANALÍTICA, NO EL CONJUNTO DE DATOS ORIGINAL.
    - Construir una visualización con Grafana que permita analizar a nivel gerencias los hallazgos principales del conjunto de datos.
    - Entregar las conclusiones de proceso realizado
    - Generar un documento  completo que evidencie todos los procesos realizados siguiendo normas APA o IEEE
    - Construir el documento en Google Docs / Word, de manera colaborativa. (Compartir el enlace del documento construido a rodolfo.meza@gmail.com con posibilidad de edición)
    - En el reporte en Google Docs o Word copiar los resultados de los analisis realizados, la explicación de las fases desarrolladas y las evidencias de todo el proceso.
    - Adicionar los notebook y scripts de python usados para el análisis mediante un repositorio de Github

2. Rúbrica. Se verificará el nivel de cumplimiento en cada uno de los puntos solicitados

El 10 de Octubre se deberá realizar una presentación por parte de una persona del grupo elegida al azar.  10 minutos por cada grupo. Resumen ejecutivo. Para esa fecha el proyecto ya deberá contar con todo el análisis para responder a cualquiera de los puntos (a,b,c,d...l)

Una semana despúes deberán entregar el documento final teniendo en cuenta la retroalimentación recibida.
